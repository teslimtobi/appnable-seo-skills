# Appnable SEO plugin for Claude

An SEO content agent for Appnable (appnable.com) and KoKoodi (kokoodi.com).

- **seo-keyword-research** skill: keyword research with free SEO tools and a Word report for approval.
- **seo-article-writer** skill: ~1,500-word articles in the Appnable house style (keyphrase x7, four "Read also" links, FAQs, references) as Word files.
- **/seo-article** command: runs the whole workflow, research then approval then writing.

Install in Claude: Customize > Plugins > Add > Upload, and choose `appnable-seo.zip`.
Then just ask: "Research two SEO topics for Appnable", or type `/seo-article 2 topics`.
